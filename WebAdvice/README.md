# 🎯 ADVICE อ่างทอง - เกมเปิดแผ่นป้ายทายภาพปริศนา (35 ป้าย 1 รูปคำตอบ)

เว็บไซต์เกมเปิดแผ่นป้ายทายภาพ ออกแบบเฉพาะสำหรับ **ร้าน ADVICE สาขาอ่างทอง** สำหรับใช้ประกอบการถ่ายทำคอนเทนต์วิดีโอ TikTok, Reels, Facebook Shorts และ YouTube Shorts สไตล์เกมโชว์ยอดฮิต ลุ้นระทึก สนุกสนาน พร้อมใช้งานได้ทันที

---

## 🎮 รูปแบบการเล่น (เกมโชว์เปิดป้ายทายภาพ 1 รูปคำตอบ)
1. **รูปคำตอบ 1 รูป :** อัปโหลดรูปภาพคำตอบเพียง 1 รูป (เช่น ภาพสินค้าลับ, รางวัลใหญ่, หรือภาพบุคคล) ระบบจะซ่อนรูปภาพนั้นไว้ด้านหลังกระดาน
2. **ตาราง 35 ป้ายปิดทับ :** ด้านหน้าจะมีแผ่นป้ายสีฟ้าพร้อมตัวเลข 1–35 เรียง 5 แถว 7 คอลัมน์ ปิดบังภาพคำตอบไว้ทั้งหมด
3. **เปิดป้ายทีละช่อง :** เมื่อผู้เล่นหรือพิธีกรคลิกเลือกเปิดป้ายใด ป้ายนั้นจะค่อย ๆ จางหายไปและเผยให้เห็นเฉพาะส่วนของรูปภาพคำตอบที่อยู่ตรงช่องนั้น
4. **ลุ้นตอบคำถาม :** ผู้เล่นค่อย ๆ เปิดป้ายไปเรื่อย ๆ จนกระทั่งทายคำตอบได้ถูก
5. **ปุ่มเปิดทั้งหมด (เฉลยภาพ) :** เมื่อมีคนทายถูก หรือต้องการเฉลย ให้กดปุ่ม **"เปิดทั้งหมด (เฉลยภาพ)"** ป้ายทั้ง 35 ช่องจะหายไปพร้อมกัน และเผยให้เห็นภาพคำตอบแบบเต็ม ๆ สวยงาม พร้อมพลุ Confetti ฉลอง

---

## 🎨 ธีมและเอกลักษณ์ ADVICE (60 : 30 : 10)
- **สีฟ้า (60%):** สีน้ำเงิน/ฟ้าเอกลักษณ์ของ Advice บ่งบอกถึงความเป็นผู้นำไอที
- **สีเหลือง (30%):** สีเหลืองสดใส ป้าย ตัวเน้น และขอบนีออน สื่อถึงความสดชื่น สนุกสนาน
- **สีขาว (10%):** ตัวเลขอารบิก 1–35 ขนาดใหญ่ คมชัด สบายตา เห็นเด่นชัดผ่านหน้าจอมือถือ

## 🕹️ ปุ่มควบคุมบนแถบเครื่องมือ

| ปุ่มควบคุม | รายละเอียดการทำงาน |
| :--- | :--- |
| **🖼️ อัปโหลดรูปคำตอบ** | เลือกรูปภาพคำตอบ 1 รูปมาซ่อนไว้หลังป้าย 35 ช่อง (มีระบบพรีวิว) |
| **🔄 เริ่มเกมใหม่** | ปิดแผ่นป้ายทั้ง 35 ช่อง เพื่อเริ่มเล่นเกมรอบใหม่ (คีย์ลัด: `R`) |
| **🎲 สุ่มเปิด 1 ป้าย** | สุ่มเลือกและเปิดแผ่นป้ายที่ยังปิดอยู่ 1 ช่องเพื่อแจกเบาะแส (คีย์ลัด: `Q`) |
| **👁️ เปิดทั้งหมด (เฉลยภาพ)** | เปิดแผ่นป้ายทั้ง 35 ช่องเพื่อเฉลยภาพคำตอบเต็มตา พร้อมพลุ Confetti |
| **🙈 ปิดทุกป้าย** | คว่ำแผ่นป้ายทั้งหมดลงอย่างรวดเร็ว |
| **🔊 เปิด/ปิดเสียง** | สลับเสียง Sound Effects (เสียงเปิดป้าย, เสียงกลอง, เสียงกระดิ่ง, เสียงฉลอง) |
| **⛶ เต็มจอ** | สลับโหมดเต็มหน้าจอ Fullscreen เหมาะสำหรับอัดวิดีโอ (คีย์ลัด: `F`) |
| **🎬 โหมดถ่ายคลิป** | ซ่อนเมนูรบกวนตา ให้เห็นเฉพาะภาพและกระดานเกมเน้น ๆ |
| **🔔 ซาวด์พิธีกร** | ปุ่มเสียงสำหรับพิธีกร: ถูกต้อง (Ding-Dong!), ตอบผิด (Buzzer!), ลุ้นระทึก (Drumroll) |

---

## ⌨️ คีย์ลัดสำหรับพิธีกร (Host Hotkeys)
- **`1` หรือ `Z`** : เสียงตอบถูก (Ding-Dong! 🔔)
- **`2` หรือ `X`** : เสียงตอบผิด (Buzzer! ❌)
- **`3` หรือ `C`** : เสียงกลองลุ้นระทึก (Drumroll 🥁)
- **`Q`** : สุ่มเปิด 1 แผ่นป้าย (Random Reveal 🎲)
- **`R`** : เริ่มเกมใหม่ ปิดทุกป้าย (Reset 🔄)
- **`F`** : สลับโหมดเต็มหน้าจอ (Fullscreen ⛶)
- **`M`** : เปิด / ปิดเสียง (Mute / Unmute 🔊)
- **`Escape`** : ปิดหน้าต่างอัปโหลด
